# TeamUp Prototype

A mobile-first sports team hub prototype for Hong Kong amateur teams.

## Current prototype

- Team home and activity feed
- Team chat and event discussions
- Events, calendar and RSVP
- Member list
- Traditional Chinese / English switch
- Installable PWA support

## Important

This is an early testing prototype. Demo data and changes are stored only in each browser using localStorage, so teammates will not yet share the same live data or accounts.

The next build phase is a shared backend, login and team invitations.
